# Senhas recusadas para credencial NOVA.
#
# A lista é curta de propósito. O piso de 15 caracteres já elimina quase toda
# a cauda dos vazamentos públicos (rockyou e afins são dominados por senhas de
# 6 a 10 caracteres); o que sobra, e o que esta lista cobre, são as senhas
# LONGAS que as pessoas inventam justamente para satisfazer um piso de
# comprimento — repetir uma palavra, subir a linha do teclado, contar até
# quinze. São exatamente os primeiros palpites de quem ataca uma base que
# exige senha longa.
#
# Formato: uma senha por linha, em minúsculas. Linha vazia e linha iniciada
# por '#' são ignoradas. A comparação é feita em minúsculas, então "Senha"
# e "SENHA" batem na mesma entrada.
#
# Ao acrescentar entradas: só senhas com pelo menos TamanhoMinimoSenha
# caracteres têm efeito — as menores já são recusadas pelo comprimento, e
# mantê-las aqui só faz a lista parecer maior do que é.
